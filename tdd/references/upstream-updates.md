# Requested upstream maintenance

Read this only when checking or updating tdd from its recorded sources.
Ordinary test-driven development does not fetch upstream or require another skill.

Use `agent-instructions` by name from the installed skill catalog for requested
source maintenance, with this folder as the target.
If this maintenance-only dependency is unavailable, report the blocker and
preserve the source pins. Ordinary use remains available.

"Check tdd for upstream changes" selects Check mode without editing files or
pins. "Update tdd from upstream" authorizes compatible changes and validation
in Update mode. Neither request creates a background schedule.

Read `../origin.txt` for the immutable baseline, review cursor, source paths,
borrowed ideas, and local choices. Preserve independent invocation, meaningful
red-before-green evidence, independent expectations, proportionate refactoring,
and existing user authority. New donor approval gates, dependencies, or delivery
steps do not become local requirements automatically. The shared procedure owns
fetching, moved paths, classification, validation, and cursor advancement.
