# Daily meeting update — deprecated

Use `report-work-activity` for period summaries, work/open-source metrics, retained
HTML evidence and outstanding commitments or assignments. Resolve it by name in
the installed catalog. If unavailable, report the missing replacement instead of
running the retired interview or presenting the old digest as equivalent.

The legacy OpenCode digest has been retired. The replacement selects conversation
activity by message time and uses the available host history tools or supported
local stores.
