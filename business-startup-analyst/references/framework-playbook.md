# Framework Playbook

## 1) Problem and Customer Fit

Use this statement format:

`[Customer segment] struggles with [job/problem] in [context], causing [measurable cost].`

Minimum evidence for a strong problem claim:
- Repeated behavior from real users (not opinions only)
- Measurable impact (time, money, risk, compliance)
- Existing workaround that proves urgency

## 2) Assumption Map

Track assumptions in six buckets:
- Problem (is pain real and frequent?)
- Demand (will users switch/pay?)
- Differentiation (why this over alternatives?)
- Distribution (can we acquire customers efficiently?)
- Economics (can unit economics work?)
- Execution (can this team ship and sell?)

Tag each assumption as:
- `known` (evidence-backed)
- `inferred` (reasonable but not validated)
- `untested` (high risk)

## 3) Market Sizing

Always prefer bottom-up first, then triangulate top-down.

Bottom-up core formula:

`TAM = potential_customers x annual_revenue_per_customer`

`SAM = TAM x serviceable_filters`

`SOM = SAM x realistic_capture_rate`

Reasonable SOM default for early-stage startup:
- Year 3: 1-3% of SAM
- Year 5: 3-6% of SAM

If bottom-up and top-down differ by >30%, explain why.

## 4) Competitive Analysis

Analyze three layers:
- Direct competitors
- Indirect substitutes
- Status quo behavior (do nothing/manual process)

Wedge statement template:

`The only [category] for [segment] that [specific differentiated outcome].`

Defensibility checks:
- Can incumbents copy quickly?
- Does wedge require unique data/workflow access?
- Is there switching cost or embedding effect?

## 5) Unit Economics

Use these baseline formulas:

`CAC = total_sales_marketing_spend / new_customers`

`LTV = ARPU x gross_margin x (1 / churn_rate)`

`payback_months = CAC / (ARPU x gross_margin)`

Healthy baseline targets (context-dependent):
- LTV/CAC >= 3.0
- Payback <= 12 months (<=18 acceptable early)
- Gross margin suitable for model (SaaS often 70%+)

## 6) GTM Feasibility

Select one beachhead segment first.

Channel plan must include:
- Channel
- Cost profile
- Conversion assumptions
- Time-to-signal

Leading indicators for first 90 days:
- Qualified pipeline volume
- Activation rate
- Week-4 retention
- Paid conversion rate

## 7) Scenario Design

Model at least 3 scenarios:
- Conservative: slower growth, weaker conversion, higher churn/CAC
- Base: most likely assumptions
- Upside: stronger conversion/retention with realistic constraints

State what must be true for each scenario to happen.

## 8) Decision Logic

Weighted score dimensions:
- Problem severity and urgency: 20%
- Market attractiveness: 20%
- Differentiation defensibility: 15%
- Unit economics viability: 20%
- GTM feasibility: 15%
- Execution fit: 10%

Decision bands:
- `>= 75`: GO
- `60-74`: CONDITIONAL GO
- `45-59`: PIVOT
- `< 45`: NO-GO

Always pair the decision with top 3 experiments to de-risk.
