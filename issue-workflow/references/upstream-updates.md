# Requested source maintenance

Read only for a requested source check or update. Resolve `agent-instructions`
by registered name and use its maintenance procedure with this skill and
`../origin.txt`. If unavailable, report that dependency and leave pins unchanged;
ordinary ticket synchronization does not depend on it.

Checking leaves instructions and source cursors unchanged. Updating authorizes
compatible changes and validation; neither operation schedules future work.
The shared owner handles acquisition, renames, licenses, review and cursor updates.

Preserve project-owned transition rules, actual event evidence, exact ticket
identity, source guards, single mutation ownership and uncertain-write recovery.
Matt supplies the project policy location; ECC supplies allowed Jira transition
discovery. Do not import their full setup, issue creation, comments, labels,
assignees or fixed postmerge states. Provider documentation remains a separate
reference, and a skill file does not implement unattended merge delivery.
