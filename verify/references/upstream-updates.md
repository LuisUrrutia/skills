# Requested source maintenance

Read this only when checking or updating verify from its recorded sources.
Ordinary verification does not fetch skill sources.

Resolve `agent-instructions` by registered name with this skill as the target.
It owns the shared Check or Update procedure. Read this skill's `origin.txt`
for exact sources and local choices. Check mode leaves files and pins unchanged;
Update mode validates compatible changes before advancing the reviewed range.
Neither request schedules background work.

Preserve claim-specific evidence, project-local verification ownership, current
input/build identity, real user paths and side effects, cleanup with retained
proof, and honest partial or blocked outcomes. Donor-specific tools, mandatory
repairs, and repeated checks without a relevant change do not become local rules.
