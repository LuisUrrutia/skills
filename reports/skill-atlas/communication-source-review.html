Communication and documentation · 4 October 2026

One prose owner, one documentation specialist

communicate-clearly replaces humanize, preserving meaning, voice and repairs for artificial writing patterns. write-documentation adds structure, source accuracy and a verified path for the reader.

Open the atlasRead the source evidence

Communicate clearly

Default guidance for answers, explanations, drafts, rewrites and prose reviews. It adapts to the reader, language, channel and requested depth. An expert gets useful precision; a newcomer gets the missing concepts.

Existing claim-by-claim fidelity, author voice, dialect and pattern false-positive protections survive the rename. The catalog stays conditional. Writing patterns guide repairs, not authorship detection.

Write documentation

A specialist for guides, READMEs, reference, runbooks and decision records. It verifies the version, commands, prerequisites, expected outcomes, source claims and links that make a document usable.

It keeps existing conventions and useful mixed pages. Documentation does not authorize a production command, a new docs platform or publication.

Why adapt instead of install unchanged?

The existing prose owner already protects meaning better than a keyword-removal workflow. The selected sources add audience and channel choices, conceptual prerequisites, document structure and reader checks. Combining these decisions avoids two automatic writers competing for the same text.

The adaptation excludes mandatory style profiles, saved author personas, teaching workspaces, per-paragraph approval, fixed sentence counts, English-only grammar and vendor toolchains. Ordinary writing should stay proportionate to the request.

Clarity across languages

Transfer stable terminology, explicit relationships and conditions before actions. Use the target language's natural grammar, register and punctuation. Preserve protected quotations, code, placeholders, quantities and qualifications. STE100 remains a controlled-English standard; this package does not claim multilingual STE compliance.

The ISO public abstract supports plain-language guidance across written languages. Full ISO and STE standards were not read. The source record distinguishes public evidence, search-indexed evidence and direct access limits.

Selected incorporation is narrower than adopting an entire upstream skill. Tool-specific procedures remain with their existing owners.
