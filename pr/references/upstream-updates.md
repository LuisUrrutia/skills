# Requested source maintenance

Read only when asked to check or update this skill from its recorded sources.
Resolve `agent-instructions` by registered name and use its maintenance procedure
with this skill as target. Read `../origin.txt` for exact revisions and choices.
Check mode leaves files and pins unchanged; Update mode incorporates compatible
changes and validates them. Neither mode creates a schedule.

Preserve exact fork/head/base identity, claim evidence and repository requirements. Add useful review evidence without a mandatory visual or donor template. No blanket reconfirmation or automatic follow-up.

Local snapshots are compared by content hash, not an inferred remote feed.
The shared procedure owns source acquisition, rename tracking, classification and cursor updates.

For GitHub CLI updates, preserve direct attachment uploads, current-head capture
provenance, body readback and partial-failure recovery. The installed command help
establishes available flags; gh-skill self-management is outside PR presentation.
