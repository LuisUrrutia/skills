# Requested source maintenance

Read only for a requested check or update of this skill's recorded sources.
Resolve `agent-instructions` by registered name and use its maintenance procedure
with this skill as the target. If unavailable, report the missing dependency and
leave source pins unchanged; ordinary error-contract work remains usable.

"Check error-handling for upstream changes" selects Check mode without edits.
"Update error-handling from upstream" authorizes compatible changes and validation.
Neither request creates a schedule. Read `../origin.txt` for source revisions,
review cursors, borrowed ideas and local decisions.

Preserve project error contracts, language independence, causal evidence, explicit
partial or unknown outcomes, cancellation, bounded recovery and replay safety.
ECC contributes failure representation and caller-facing boundaries; pstack
contributes boundary ownership, reconciliation and behavior-based checks.
Do not import ECC's fixed AppError/envelope, broad default retry or unrestricted
logging, or pstack's unconditional internal trust and absolute test-deletion rules.
The shared procedure owns acquisition, rename tracking, validation and cursor updates.
